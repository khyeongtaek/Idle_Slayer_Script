# Idle Slayer 매크로 (한글판)

[Devil4ngle/Idle_Slayer_Script](https://github.com/Devil4ngle/Idle_Slayer_Script) 를 한글로 옮기고 몇 가지 기능을 덧붙인 버전입니다.

**게임 자체는 영어로 두고 써야 합니다.** 이 매크로는 화면의 특정 위치 색을 읽어서 상황을 판단하기 때문에, 게임 언어를 바꾸면 글자 위치가 달라져서 동작하지 않습니다. 한글로 바꾼 것은 매크로 프로그램의 화면과 설명뿐입니다.

(Steam 판 · Windows 에서만 동작합니다)

---

## 한글판에서 추가된 기능

### 1. 미니언 관련 설정

승천 업그레이드 **리더십 마스터**가 있어야 [모두 받기] / [모두 보내기] 버튼이 생겨서 미니언 처리가 한 번에 끝납니다. 이 업그레이드가 없는 경우를 위해 옵션 두 개를 추가했습니다.

[일반] 탭에 있습니다.

| 옵션 | 설명 |
| --- | --- |
| **미니언 자동 수집** (기본 켜짐) | 끄면 미니언 관련 동작을 아예 하지 않습니다. 아래 방식이 잘 안 되면 이걸 끄세요. |
| **리더십 마스터 없음 (개별 수집)** (기본 꺼짐) | [모두 보내기] 버튼이 안 보일 때 켜세요. 미니언 목록의 버튼을 위에서부터 하나씩 눌러 보상을 받고 다시 임무에 보냅니다. |

> **동작 방식 (실제 게임 화면에서 확인함)**
>
> 미니언마다 버튼이 하나씩 있고, 상태에 따라 색이 다릅니다. 원본의 퀘스트 수령과 같은 방식으로
> 버튼 색을 찾아 그 자리를 누릅니다.
>
> | 버튼 | 색 | 처리 |
> | --- | --- | --- |
> | `Claim Reward` | `0x11A622` (초록) | 누름 — 보상 수령 |
> | `Send on Mission` | `0x541787` (보라) | 누름 — 임무 보내기 |
> | `On a Mission...` | `0x975DCA` (밝은 보라) | **찾지 않음** — 임무 중이라 건드리면 안 됨 |
>
> 보상을 받으면 그 자리가 `Send on Mission` 으로 바뀌므로 **수령을 먼저 전부 하고, 그 다음 보내기**를 합니다.
>
> 포인트가 모자라면 눌러도 `Send on Mission` 색이 그대로 남습니다. 그래서 한 번 처리한 버튼
> **아래에서부터** 다시 찾도록 해서 같은 자리를 반복해 누르는 일이 없습니다.
>
> [로그] 탭에서 `받은 미니언 보상` / `임무 보낸 미니언` 숫자로 확인할 수 있습니다.

### 2. 승천 실패 시 화면 닫기

승천 포인트가 0이면 승천이 안 되는데, 원본은 이때 열어 둔 승천 화면을 그대로 두고 끝나서 이후의 모든 클릭이 그 화면에 막혔습니다. 이제 승천할 수 없거나 승천에 실패하면 **ESC → (그래도 안 닫히면) 나가기 버튼** 순서로 화면을 다시 닫습니다.

[로그] 탭의 `자동 승천 성공` / `포인트 부족으로 건너뜀` 숫자로 확인할 수 있습니다.

### 3. 보너스 스테이지 시작 대기 시간을 스테이지별로 따로 지정

보너스 스테이지에 들어가면, 매크로는 정해진 시간만큼 기다렸다가 미리 짜 둔 점프 순서를 시작합니다.
이 대기 시간이 맞지 않으면 첫 구간의 기준점을 놓쳐서 스테이지를 통째로 실패합니다.

원본은 스테이지 2 와 3 에 **같은 값(3900ms)** 을 썼지만, 두 스테이지는 시작 연출 길이가 서로 달라서
값을 따로 둘 수 있게 바꿨습니다.

`Libraries\BonusStage.au3` 파일 맨 위에 있습니다.

```autoit
Global Const $iBonusStage2StartDelay = 2900   ; 보너스 스테이지 2
Global Const $iBonusStage3StartDelay = 3900   ; 보너스 스테이지 3
```

> **값을 바꾸는 방법**
>
> 1. `Libraries` 폴더의 `BonusStage.au3` 를 메모장이 아니라 **AutoIt Script Editor(SciTE)** 로 엽니다.
>    (메모장으로 저장하면 한글이 깨집니다. 이 파일은 UTF-8 BOM 으로 저장되어 있습니다.)
> 2. 파일 맨 위의 위 두 줄에서 **숫자만** 바꿉니다.
> 3. 저장한 뒤 `Idle Runner.au3` 를 다시 컴파일합니다.
>
> 숫자를 **키우면 더 늦게** 시작하고, **줄이면 더 일찍** 시작합니다.
> 해당 스테이지가 자꾸 실패하면 **100 단위로** 조금씩 바꿔 가며 맞추세요.

### 4. 다음 실행까지 남은 시간 표시

[일반] 탭의 **자동 업그레이드 구매**와 **자동 승천** 오른쪽에, 다음 실행까지 남은 시간이 1초마다 표시됩니다.

- `9분 58초` / `2시간 04분 58초` 처럼 표시됩니다.
- 시간이 다 되면 `곧 실행` 으로 바뀝니다.
- 해당 기능을 꺼 두면 아무것도 표시되지 않습니다.

> **주기 타이머는 [정지] 를 눌러도 초기화되지 않습니다.**
> `TimerInit` / `TimerDiff` 기반이라 정지 중에도 실제 시간이 계속 흐릅니다.
> 그래서 10분 주기인데 20분 정지했다가 [시작] 하면 곧바로 실행됩니다.
> 남은 시간 표시도 정지 중에 똑같이 줄어들며, 0 이 되면 `곧 실행` 상태로 [시작] 을 기다립니다.
>
> 타이머가 초기화되는 유일한 경우는 **"자동 업그레이드 구매" 체크박스를 껐다 켤 때**입니다.
> 이때는 9초 뒤에 첫 실행이 이뤄집니다. ("자동 승천"은 껐다 켜도 초기화되지 않습니다.)

### 5. 실시간 로그 창 (항상 보임)

예전에는 왼쪽 메뉴에 [로그] 버튼이 따로 있어서, 눌러야만 기록을 볼 수 있었습니다.
이제 [로그] 버튼을 없애고 **창 아래쪽에 로그 영역을 항상 띄워** 둡니다.

- 왼쪽 : **실시간 로그** — 매크로가 방금 무엇을 했는지 시각과 함께 한 줄씩 쌓입니다.
- 오른쪽 : **통계 및 도움말** — 예전 [로그] 탭에 있던 누적 통계와 설정 안내입니다.

자세한 내용은 아래 [화면 구성](#화면-구성) 을 보세요.

> 기록 파일(`Logs.txt`)에 적히는 문구는 통계를 세는 데 쓰는 값이라 **영어 그대로** 남고,
> 화면의 실시간 로그에만 한글로 바꿔서 보여줍니다.

### 6. 분노(Rage) 오인식 방지

**증상** — 보너스 스테이지가 끝난 직후에 메가 호드가 아닌데도 가끔 분노를 써 버렸습니다.

**원인** — 분노를 쓸지 말지는 화면의 픽셀 색으로만 판단하는데, 그 판정이 너무 헐거웠습니다.

| 판정 | 보는 곳 | 문제 |
| --- | --- | --- |
| 메가 호드 | `(385, 280)` **픽셀 한 점**, 색 오차 허용 없음 | 다른 감지(상자 사냥 2점, 보스전 3점)와 달리 확인용 두 번째 점이 없습니다. |
| 소울 보너스 | `(625,143)~(629,214)` 좁은 세로줄 | 색만 맞으면 바로 `R` 을 눌렀고, 기록조차 남기지 않아 추적이 안 됐습니다. |

매크로는 이 색을 **40ms 마다** 봅니다. 그런데 보너스 스테이지가 끝나고 화면이 어두워졌다 다시 밝아지는
동안에는 그 자리의 색이 여러 단계를 거쳐 변합니다. 그러다 **우연히 딱 한 프레임만** 판정 색과 같아지면
메가 호드로 잘못 보고 분노를 씁니다. 매번이 아니라 "가끔" 일어나는 이유가 이것입니다.
(지역마다 하늘색이 달라서, 색이 지나가는 경로도 지역마다 다릅니다.)

**수정** — 색을 한 번 봤다고 바로 쓰지 않고, **같은 색이 0.25초 동안 끊기지 않고 계속 보일 때만**
진짜로 인정합니다. 중간에 한 번이라도 색이 사라지면 처음부터 다시 셉니다.
진짜 메가 호드와 소울 보너스는 몇 초 동안 이어지므로 그대로 잡히고, 화면 전환 중 한순간만 스친 색은 걸러집니다.

- 기다리는 동안 매크로를 멈추지 않으므로 은상자 줍기 같은 다른 동작은 그대로 돌아갑니다.
- 기능상 손해는 진짜 메가 호드에서 분노를 쓰는 시점이 **0.25초 늦어지는 것뿐**입니다.
- 걸러낸 경우에는 실시간 로그에 `메가 호드 잘못 본 것 걸러냄 (화면 전환 중)` 이라고 남으므로,
  실제로 몇 번이나 걸러졌는지 눈으로 확인할 수 있습니다.
- 소울 보너스 분노에도 같은 확인을 넣고, 시작할 때 `소울 보너스 - 분노 사용` 기록을 남깁니다.
  (이전에는 아무 기록도 남지 않아 원인 추적이 불가능했습니다.)

기다리는 시간은 `Idle Runner.au3` 위쪽에서 바꿀 수 있습니다.

```autoit
Global Const $iRageConfirmDelay = 250   ; 밀리초
```

> 숫자를 키우면 더 확실해지지만, 진짜 메가 호드에서 분노를 쓰는 시점도 그만큼 늦어집니다.

> **그래도 가끔 남는다면** — 보너스 스테이지 결과 화면이 (전환 중이 아니라) 멈춘 채로 판정 색과
> 같을 가능성이 있습니다. 그때는 "보너스 스테이지 직후 몇 초간 분노 판정 쉬기" 나
> "결과창이 떠 있는 동안 분노 판정 멈추기" 를 추가로 넣으면 됩니다.

### 7. "상자 사냥" 통계가 0 으로 나오던 문제 수정

기록 파일에는 `Chesthunt Started` 라고 적히는데 통계는 `Chesthunt` 를 세고 있어서, [상자 사냥] 항목이
항상 0 이었습니다. 세는 기준을 기록과 맞췄습니다. 이미 쌓아 둔 기록도 그대로 집계됩니다.

## 실행 방법

### 1) exe 파일로 실행 (쉬움)

바탕화면의 `Idle Runner_한글판_x64.exe` 를 실행하면 됩니다.

백신이 막을 수 있습니다. 매크로 프로그램은 키 입력과 마우스를 대신 조작하기 때문에 백신이 의심스럽게 보는 경우가 흔합니다. 신뢰할 수 없으면 아래 방법으로 직접 컴파일해서 쓰세요.

### 2) 소스에서 직접 컴파일 (조금 번거로움)

1. [AutoIt 전체 설치판과 AutoIt Script Editor](https://www.autoitscript.com/site/autoit/downloads/) 를 **둘 다** 설치합니다.

   (또는 명령 프롬프트에서: `winget install AutoIt.AutoIt` 그리고 `winget install AutoIt.SciTE4AutoIt3`)

2. `Idle Runner.au3` 를 우클릭하고 `Compile with Options` 를 누릅니다.

3. 메뉴에서 `Compile Script` 를 누르면 exe 파일이 만들어집니다.

> **주의:** 소스 파일들은 **UTF-8 (BOM 있음)** 으로 저장되어 있습니다. 다른 인코딩으로 저장하면 한글이 깨지니 편집할 때 주의하세요.

## 게임 설정

### 반드시 맞춰야 하는 것

- 게임 해상도 **1280x720**, **창 모드**, 디스플레이 배율 **100%**
- 게임 언어는 **영어**
- 게임 창이 **활성 상태**여야 합니다. 아니면 점프만 합니다.
- **커스텀 커서 끄기**
- 조작키 설정: 점프 = **위쪽 화살표**, 부스트 = **오른쪽 화살표**
- 윈도우 11 이면 **관리자 권한**으로 실행

### 권장 설정

- **보너스 스테이지 2, 3** 만 처리할 수 있습니다. 나머지는 [미니게임] 탭에서 "보너스 스테이지 건너뛰기"를 켜세요.
- 보너스 스테이지 2 를 하려면 승천 업그레이드 **보호(Protect)** 가 필요합니다.
- 보너스 스테이지 3 을 하려면 승천 업그레이드 **판자 발판(Board The Platforms)** 이 필요합니다.
- **수직 자석(Vertical Magnet)** 은 사지 마세요.
- 설정에서 **포탈 대화창 끄기**
- 설정에서 **반올림 대량 구매 켜기**
- 설정에서 **잠긴 퀘스트 보상 숨기기 켜기**
- 승천 고지(Ascending Heights)는 **안나 기본 스킨**을 쓰세요.

### 보스전을 돌릴 경우

- **안나 기본 스킨** 사용
- **박쥐 장궁(Bat Long bow)** 또는 멀티샷 계열 활 사용
- 스토리 모드에서 해당 보스를 한 번 이겨 둔 상태여야 합니다.

## 화면 구성

창은 **위쪽 탭 영역**과 **아래쪽 로그 영역** 두 부분으로 되어 있습니다.

### 위쪽 - 탭

| 탭 | 내용 |
| --- | --- |
| **홈** | 원본 GitHub, 디스코드, 업데이트 확인 |
| **일반** | 점프 간격, 자동 업그레이드 구매, 포탈 순환, 자동 승천, 분노 설정, 미니언 설정 |
| **미니게임** | 보너스 스테이지 건너뛰기, 자물쇠 따기 / 강화 크리스탈 세이버 보유 여부, 퍼펙트 상자 사냥 |
| **제작** | 소울 나침반, 분노 알약, 차원 / 이차원 지팡이 제작 |

각 옵션에 **마우스를 올리면 설명이 나옵니다.** 체크박스뿐 아니라 옆의 글자를 눌러도 켜고 꺼집니다.

### 아래쪽 - 로그 (항상 보임)

예전에는 왼쪽 메뉴의 [로그] 버튼을 눌러야 볼 수 있었지만, 이제 **탭과 상관없이 항상 창 아래쪽에 보입니다.**
그래서 창 세로 길이가 200 에서 462 로 늘어났습니다.

| 칸 | 내용 | 버튼 |
| --- | --- | --- |
| **왼쪽 - 실시간 로그** | 매크로가 방금 무엇을 했는지 시각과 함께 한 줄씩 쌓입니다. (예: `14:03:21  메가 호드 - 분노 사용`) | **화면 지우기** — 보이는 글자만 비웁니다. 저장된 기록과 통계는 그대로입니다. |
| **오른쪽 - 통계 및 도움말** | 위쪽은 지금까지의 누적 통계, 아래쪽은 현재 상태와 설정 안내입니다. | **새로고침** — 통계와 게임 창 상태를 다시 읽어 옵니다.<br>**기록 지우기** — 기록 파일을 지워 누적 통계를 0 으로 되돌립니다. |

> 실시간 로그는 최근 **300줄**까지만 보관하고, 넘으면 오래된 줄부터 지웁니다.
> 창을 껐다 켜면 실시간 로그는 비워지지만, 누적 통계는 기록 파일에 남아 있어 그대로 이어집니다.
>
> **오른쪽 [통계 및 도움말] 은 자동으로 갱신되지 않습니다.** 최신 값을 보려면 [새로고침] 을 누르세요.
> (기록 파일 전체를 다시 읽는 작업이라, 매크로가 도는 중에 자동으로 반복하면 잠깐씩 멈추기 때문입니다.)

> 창은 제목 표시줄을 잡고 끌어서 옮길 수 있습니다. 창이 길어졌으므로 게임 창과 겹치면 원하는 위치로 옮기세요.

## 저장되는 파일

프로그램이 있는 폴더에 `IdleRunnerLogs` 폴더가 만들어집니다.

- `Settings.txt` — 체크박스와 숫자 설정
- `Logs.txt` — 동작 기록. 이 파일 안의 문구는 통계를 세는 데 쓰는 값이라 영어 그대로 둡니다. 화면에는 한글로 나옵니다.
